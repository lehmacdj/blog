This is one possible feature that helps with implementing [override typeclasses or implicits](/9cmxkzhW9IDE/override-typeclasses-or-implicits).

[local type declarations](/F4TTPLipKTSS/local-type-declarations) are probably important in combination with this in contexts where [confluent instance resolution](/3nJYq6q6JOEA/confluent-instance-resolution) is important.

See also [this GHC proposal](https://github.com/treeowl/ghc-proposals/blob/e65674db941474db03b9cc6b58f016d427e9f922/proposals/0000-local-types.md) which demonstrates what scoped type class instances might look like in Haskell.
