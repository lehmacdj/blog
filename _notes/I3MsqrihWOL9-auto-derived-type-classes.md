Languages sometimes provide automatically derived type classes like `Send` / `Sync` in Rust or `Copyable` / `Escapable` / `Sendable` in Swift.

It would be neat if it were possible to user define auto derived type classes, or specify that within some scope a certain set of already existing type classes should be auto derived.
